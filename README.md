# 麦麦今日剧本 · 心情点餐剧场（McDonald's Mood Diner）

> 麦当劳 × WorkBuddy 创意开发大赛参赛作品
> 基于麦当劳中国官方 MCP Server（https://github.com/M-China/mcd-mcp-server）构建的**强交互 / 叙事驱动点餐体验**

## 它是什么

不是点单，是**被一出戏选中**。用户不用从冷冰冰的菜单里挑——先选心情、答 3 题小测验、再转一次大转盘，麦麦替你"读心"，从麦当劳**真实菜单**里端出今日命定的那一桌，并生成带人设印章的专属小票。

把"为什么点这个"变成一段可玩、可互动、有叙事的体验，而不是又一个问答机器人。

## 三步强交互流程

1. **选心情** — 6 张拟人食物表情脸（累瘫了 / 饿狠了 / 有点丧 / 嗨起来 / 嘴馋了 / 想暖点），点选即切换场景叙事文案。
2. **答 3 题小测验** — 跟谁吃 / 钱包状态 / 热量管控，逐题生成"今日人设"标签。
3. **转大转盘** — 真实旋转动画，转盘偏向所选心情、落定"今日剧本"，**自动按测验答案精调套餐**（独食/双人/合家欢/开黑、省着点/犒劳自己、热量自由/轻负担/硬核健身），并一键端上拼盘。

之后可在戏台上**微调**（点菜单加菜、飞入拼盘、实时算价+算卡），满意即"出戏"生成专属小票。

## 设计语言（借鉴麦当劳设计范式，非仿壳）

- 品牌红黄撞色 + 米黄背景，金色拱门 M 反复出现
- 大圆角白卡、斜切/胶囊贴纸标签、拟人化食物表情 SVG（无 emoji、无 AI 紫蓝渐变）
- 桌面网页栅格布局（左菜单 + 右吸顶拼盘），不是仿微信小程序手机壳

## 强交互 & 动态效果

- 心情选择 → 场景叙事实时改写 + 拟人店员气泡回应
- 测验点选 → 人设标签实时累加
- 大转盘 → CSS 旋转动画（6 段彩色扇区 + 金拱门中心 + 红色指针），停留段与所选心情对齐
- 揭晓卡片 → 人设标题 + 标签 + 剧情描述 + 撒花
- 加菜 → 商品图**飞入拼盘**动画；实时算价（现价/原价/立省）+ 实时算卡（热量/蛋白）
- "出戏" → **撒花** + 专属**小票**（含红章"剧本通关"）

## 真实数据来源（麦当劳官方 MCP）

| 工具 | 用途 |
|------|------|
| `query-nearby-stores` | 定位门店（广州海珠广场餐厅，storeCode 1400067） |
| `query-meals` | 拉取真实门店菜单（含价格 / 图片） |
| `list-nutrition-foods` | 拉取真实营养数据（热量 / 蛋白 / 脂肪 / 碳水） |
| `calculate-price` | 官方算价核验（含取餐方式） |

> 价格与营养均来自官方 MCP 真实返回；`calculate-price` 已联调验证（巨无霸+薯条+可乐 = ¥48.5）。

## 本地运行

直接用浏览器打开 `maimai-combo.html` 即可（数据已内联麦当劳真实菜单与营养）。

## 接入 McDonald's MCP（让 Skill 真正取数）

1. 获取 MCP Token：https://open.mcd.cn/mcp/doc → 登录 → 控制台 → 激活复制
2. 在 `~/.workbuddy/mcp.json` 写入：
   ```json
   {
     "mcpServers": {
       "mcd-order": {
         "type": "streamablehttp",
         "url": "https://mcp.mcd.cn",
         "headers": { "Authorization": "Bearer <TOKEN>" },
         "disabled": false
       }
     }
   }
   ```
3. WorkBuddy 连接器管理页 → 自定义连接器 → 信任 `mcd-order` → 重启会话
